Privacy Policy

Effective Date: October 6, 2026 | Last Updated: October 6, 2026

Summary: NeoShort is an autonomous AI YouTube Shorts creation tool. We respect your privacy. We strictly access YouTube Data API only to upload videos you authorize. We NEVER sell, store, or share your personal data.

1. Information We Collect

When you use NeoShort and authenticate via Google OAuth 2.0, we collect:

  • Google & YouTube Profile Information: Your public channel title, channel handle, subscriber count, and avatar image.
  • OAuth Tokens: Encrypted access and refresh tokens strictly used to communicate with YouTube Data API on your behalf.
  • Generated Content: Video scripts, neural audio files, and metadata created for your scheduled Shorts.

2. How We Use YouTube API Data

NeoShort uses YouTube Data API Services under Google API Services User Data Policy:

  • To upload user-scheduled vertical Shorts directly to your authorized YouTube channel.
  • To retrieve basic channel statistics (subscriber count, video count) displayed in your private dashboard.
  • We NEVER read private messages, comments, or financial account details.

3. Google API Services User Data Policy Compliance

NeoShort's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Storage & Security

All authentication tokens are transmitted via HTTPS encryption and stored securely. We do not store Google passwords.

5. How to Revoke Access

You can revoke NeoShort's access to your YouTube channel at any time by visiting your Google Account Security Permissions page and removing NeoShort.
